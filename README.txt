BEASTFIT V5 EXACT MOCKUP BUILD

This version is built to closely match the generated black/gold BeastFit homepage mockup.

Files:
- index.html = homepage matching the generated mockup structure
- shop.html = shop page
- about.html = about page
- style.css = full styling
- script.js = mobile menu + shop filters
- assets/ = cropped visual assets from the generated mockup

Deploy:
1. Extract this ZIP.
2. In Netlify > Production deploys, drag the extracted folder or zip.
3. Open the live URL and hard refresh.

Notes:
- The homepage uses cropped themed assets from the generated mockup instead of blank placeholders.
- Shopify buttons are still placeholders until you create products in Shopify.
- Email form uses Netlify Forms attributes.
